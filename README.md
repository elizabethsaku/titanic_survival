# Titanic Survival Prediction

## Project Overview
This project explores the Kaggle Titanic dataset to understand which factors influenced passenger survival.

## Objectives
- Explore and clean the dataset.
- Analyze survival patterns across passenger characteristics.
- Visualize important relationships in the data.

## Tools and Technologies
- Python
- Pandas
- Matplotlib / Seaborn
- Jupyter Notebooks

## Project Structure
- `notebooks/`: Analysis and machine learning notebooks.
- `README.md`: Project documentation.

## Progress
Project in progress.

## Dataset
The dataset is available through the [Kaggle Titanic competition](https://www.kaggle.com/competitions/titanic).
